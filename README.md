# College Practicals and Reports

## About This Repository
This repository contains my college practical assignments and academic reports. It includes IBM Cognos Analytics practicals and a Descriptive Analytics report prepared as part of my coursework.

## IBM Cognos Analytics Practicals

### Practical 1: Generate a First RetailPulse Report
Created a list report using Region, Product Category, and Sales Amount.

### Practical 2: Build a Grouped RetailPulse Sales List Report
Grouped sales data by Region and Store Name, formatted currency, and added summary totals.

### Practical 3: Filter RetailPulse Sales by Region and Date
Applied Region and date-range filters and created a prompted filter.

### Practical 4: Build a RetailPulse Region-Product Crosstab
Created a crosstab using Region, Product Category, Sales Amount, and Quantity with summary totals.

### Practical 6: Build the RetailPulse Customer Insights Dashboard
Created a dashboard with a summary card, customer trend chart, loyalty-segment bar chart, and Region filter.
